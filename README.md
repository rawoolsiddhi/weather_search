
# Weather Search App

A simple weather search engine using Flask backend + OpenWeather API + HTML/CSS/JS frontend.

## Features
- Search weather by city
- Shows temperature, humidity, wind, description
- Backend caching for faster results
- REST API following proper structure

## Run Backend
- cd backend
- pip install -r requirements.txt
- python app.py
- http://127.0.0.1:5000/
